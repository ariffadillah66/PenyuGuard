Manajemen Data Oseanografi

Impor dan kelola data SST, klorofil-a, dan salinitas untuk analisis oseanografi Pulau Rinca.

Format CSV menerima kolom bulan,tahun,bulan_angka,sst_mean_c,sst_min_c,sst_max_c atau year,month,sst_mean_c,sst_min_c,sst_max_c — satu baris per bulan. Nilai minimum/maksimum SST boleh kosong; nilai rata-rata wajib ada. Periode yang sudah ada akan diperbarui; baris tanpa nilai utama atau format tanggal yang valid akan dilewati. Untuk Supabase, jalankan SQL tambahan database/oceanographic_tables.sql terlebih dahulu.
